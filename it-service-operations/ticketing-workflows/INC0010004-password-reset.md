# INC0010004 Password Reset

| Number | Caller | Assignment Group | Short Description |
|---|---|---|---|
| INC0010004 | Dave Dixon | IT Help Desk | User forgot password, needs reset |

## Workflow

Navigate to ADUC and locate the user's standard account in `_Users\IT`. Right-click and select `Reset Password`. Select `User must change password at next logon` to ensure security.

<img width="1280" height="753" alt="20-password-reset" src="https://github.com/user-attachments/assets/aeb33d4e-9b9a-47fc-bef3-a26070f1182c" />

Select `OK` to apply.

<img width="1280" height="753" alt="21-password-reset" src="https://github.com/user-attachments/assets/fdddd7e0-18f7-4b87-a51c-95e46c9539bf" />

Provide relevant information in the ticket and close.
