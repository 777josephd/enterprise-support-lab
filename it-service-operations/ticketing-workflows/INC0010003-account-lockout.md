# INC0010003 Account Lockout

| Number | Caller | Assignment Group | Short Description |
|---|---|---|---|
| INC0010003 | Alice Anderson | IT Help Desk | User account locked out, unable to log in |

## Workflow

Navigate to ADUC, locate the user's account and verify: `Unlock account. This account is currently locked out on this Active Directory Domain Controller.`

<img width="1280" height="752" alt="16-lockout-before" src="https://github.com/user-attachments/assets/e6786292-ba90-4245-a594-0ba509869954" />

Check `Unlock account.` Then `Apply`.

<img width="1280" height="753" alt="17-lockout-after" src="https://github.com/user-attachments/assets/85ad6096-8f4f-4a94-a8e0-703ba1124192" />


Resolution notes provided with relevant information and the ticket is closed.
