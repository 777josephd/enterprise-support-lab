# Microsoft 365 Administration

This directory covers Microsoft 365 administration tasks performed at L1/L2 scope: identity management, user lifecycle, access and authentication.

## Environment Context

SterlingEnterprises is a simulated tenant using Entra ID Free.

>Note: M365 licensed services are out of scope for the current environment.

## Scope Boundary

The work in this directory reflects L1/L2 help desk operations, such as identity troubleshooting, account lifecycle, access management, and log investigation.  

No infrastructure architecture and no tenant-level configuration beyond what a support technician might perform.
